pc-agent is installed

The service runs now, unless you cancelled a dialog. In Home Assistant, the device shows the event ApplicationStarted within a few seconds.

If the agent could not start or connect, a dialog told you so.

Check the agent

  • Log: tail -f /var/log/pc-agent.log
  • Service: sudo launchctl print system/pc-agent

If you cancelled a dialog

The installer wrote the example configuration and did not start the service.

  • Edit /etc/pc-agent/config.toml (broker address, user, password, device names).
  • Start the service: sudo launchctl bootstrap system /Library/LaunchDaemons/pc-agent.plist

Uninstall

sudo /usr/local/share/pc-agent/uninstall.sh (add --purge to remove the configuration and the log too).
